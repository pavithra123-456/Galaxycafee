# ☕ Galaxy Cafe Website

A modern and responsive cafe website designed for coffee lovers. 
Galaxy Cafe provides an attractive homepage with a coffee-themed background, 
simple navigation, and an elegant design to create a pleasant user experience.

## 🌟 Features

- Attractive homepage with a coffee background image
- Responsive navigation bar
- Modern and elegant dark-themed design
- Beautiful hero section with welcome message
- Highlighted text with yellow and white colors
- Explore Menu button
- Contact Us button
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap (if used in your project)

## 📸 Website Preview

The homepage includes:
- Galaxy Cafe branding
- Home, About, Menu, Services, Gallery, and Contact navigation links
- A coffee-themed hero section
- Explore Menu and Contact Us buttons
